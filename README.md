# Türktok

Vertikaler YouTube-Kurzvideo-Feed für drei feste Themen:

- Erdogan Düzenlemeleri
- Atatürk düzenlemeleri
- Halay mix

Die App nutzt die offizielle YouTube Data API v3 zur Suche und den eingebetteten YouTube-Player zur Wiedergabe. Beim ersten Start wird ein YouTube Data API Key abgefragt und lokal im Secure Store gespeichert.

Der Android-Build läuft über GitHub Actions und erzeugt ein Debug-APK als Workflow-Artefakt.
